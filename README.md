# GitHub Pages redirect

This static GitHub Pages site immediately redirects visitors to:

- https://uia.conaf.cl/

## Publish

1. Create an empty GitHub repository named `github-pages-redirect`.
2. Push this folder to its `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. GitHub Pages will publish the redirect at `https://<GitHub-user>.github.io/github-pages-redirect/`.

For a user/organization Pages site (`https://<GitHub-user>.github.io/`), the repository must be named `<GitHub-user>.github.io`.
